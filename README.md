# Cyber Security Piscine

Small cybersecurity training exercises focused on scripting, network requests, and low-level inspection.

## Contents

- `request.py` - Python request automation / web interaction practice
- `spider.cpp` - C++ crawler-style exercise for collecting and inspecting remote resources

## What it demonstrates

- Comfort switching between Python and C++
- Basic web request automation
- Parsing and extracting useful data
- Security-oriented experimentation in small, auditable programs

## Run

Python script:

```bash
python3 request.py
```

C++ exercise:

```bash
c++ -Wall -Wextra -Werror spider.cpp -o spider
./spider
```

## Notes

These exercises are learning-focused and should be run only against systems where you have permission to test.
